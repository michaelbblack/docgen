Use Handlebars syntax in text content:

{{name}} - variable

{{#if show}}...{{/if}} - conditional

{{#each items}}...{{/each}} - loop

{{{rawHtml}}} - unescaped HTML

Three ways to add images:

1. Server path (uploaded or static):

"logo": "/assets/uploads/logo.png"

2. Data URI (embedded in JSON):

"logo": "data:image/png;base64,..."

3. External URL:

"logo": "https://example.com/logo.png"

In templates, use: <img src="{{logo}}">
